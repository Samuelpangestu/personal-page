QA Platform Local Recorder v2 Privacy Policy

Last updated: 6 November 2026. This policy covers QA Platform Local Recorder v2, version 0.3.6.

This extension records actions and assertions and provides optional agent assistance in one user-selected browser tab using bundled Playwright CRX code. Stop & import sends a Playwright draft to the authorized QA platform session that started the recording. Browser help can inspect controls and perform bounded actions requested by that session's agent. No local companion or terminal command is required.

Publisher: Samuel Pangestu G Tobing. The extension uses browser interactions and page content to generate test drafts and provide the browser assistance requested from your QA Platform session.

Debugger access

The browser debugger permission allows the extension's local recording engine to read and interact with page content, including signed-in content, frames and navigation. Browser warnings describe this broad technical capability. The integration attaches the selected test tab. Additional tabs, including popups, require explicit selection in the recorder tools; unrelated existing tabs are not selected automatically. Use an approved test profile and account. Recording performs real actions and can change website data.

What is handled locally

Tab titles and URLs are read to offer a tab selector in the originating QA Platform page; tab identifiers and titles are shared with that page for explicit selection. Playwright handles page DOM, selectors, action values and assertion content in volatile browser memory to generate code. Raw values can therefore exist in the bundled engine's memory during a recording. The extension does not claim to prevent the engine from reading them.

Before extension draft storage, display, copy, download or upload, generated fill/type/select values, file names and text/value/ARIA assertion arguments are replaced with placeholders. Navigation query parameters, fragments and credentials are removed from generated navigation commands. Selectors, accessible names and URL paths remain in the draft and can themselves contain sensitive information. Review them before sharing or import; redaction is not a guarantee that all page data is anonymous.

Storage and transmission

Browser-session storage retains the sanitized draft, target URL, scenario name, session identifier and temporary signed upload token. Stop & import sends that draft and recording metadata to the exact originating platform session over HTTPS for deployed platforms. Development deployments also support HTTP localhost. Website cookies, login storage, screenshots, network logs and storage-state exports are not included in this upload. The extension has no analytics or advertising destination and executes no remotely hosted JavaScript.

Browser help sends up to ten bounded control descriptions from the selected tab: element tag, role, accessible name, test ID, placeholder, non-sensitive input type, disabled/read-only state, page origin/path and short-lived element references. It does not send screenshots, full HTML, cookies, browser storage or values entered by the user. Agent-generated non-sensitive fill/select values pass through the authorized Platform command channel and are removed from the pending command after completion. Password, PIN, OTP, token, payment and credential-like fields are blocked and must be entered manually while assistance is paused.

Successful import and Cancel clear the retained draft and upload token and detach the local debugger. Failed imports retain the sanitized draft for explicit retry. Browser-session storage survives service-worker suspension but ends with the browser session. Raw engine memory is discarded when its context ends; sanitized recovery does not recreate the full in-memory engine state. Imported drafts follow the platform's own access and retention settings, and local Cancel does not delete previously imported data.

Your controls and limits

Choose a test tab and confirm Attach tab & record inside QA Platform. Pause, Resume, Pick locator, assertion tools, Clear draft, additional-tab attachment, Stop & import and Cancel are controlled from that same page. Browser help separately offers Connect, Pause agent, Resume agent, Tunjukkan elemen and Disconnect. Recording and browser help cannot control a tab at the same time. A small Stop & import control also appears in each explicitly attached recording tab, using an isolated browser context. Both stop controls import into the originating Platform session. Failed imports keep the draft and allow retry. No additional recorder window opens. A local session is limited to 500 actions or 4 hours. Keep the browser and originating Platform session open until import, disconnect or cancel. Agent assistance is authoring help and never a verified test result. Native file-dialog recording requires manual verification. Browser and engine limitations may affect closed shadow roots or protected pages.

Removing the extension deletes its local data but does not delete imported platform sessions. For platform data removal, contact the administrator through your existing support channel. Publisher profile: Samuelpangestu on GitHub.

Use and sharing

The extension sends recording data and browser assistance metadata to the QA Platform session you authorize. Its use and transfer of information follows the Chrome Web Store User Data Policy, including the Limited Use requirements. It does not sell user data, use it for advertising, or use it to determine creditworthiness or for lending. Platform access and any processing by its configured agent are governed by your organization’s platform settings; review those settings before sending test content.

Contact and deletion requests

For questions about this extension or this policy, contact samuel@samuelpgt.com. For deletion of imported drafts and platform sessions, contact your QA Platform administrator. Do not include passwords, upload tokens or private recording content in an email.
